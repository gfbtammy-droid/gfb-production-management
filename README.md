# GFB Production Management

Production job order tracking for GFB Food Sdn Bhd: job planning and release, mixing and packing output, QC results, transfers to store, wastage control and production loss reports.

- Web app: https://gfbtammy-droid.github.io/gfb-production-management/
- Interface: Bahasa Malaysia (default) and English
- Data: Supabase project `gfb-production`, protected by row level security and role rules (Admin, Planner, Production Supervisor, QC, View Only)

The page holds no data or passwords. Users must sign in with an account created by the admin.
